# DSA v2.9.1 AgentOps Edition

`dualstream.compact` implements the metadata-amortized CI-Lite artifact layout. Sequence headers carry stable metadata and chunk headers carry `chunk_index`, `first_token_index`, and `token_count`-equivalent record counts. Token records carry only token-varying candidate ids, quantized scores, chosen-rank data, adaptive top-K delta, fallback chosen id for rank overflow, and flags.

CI-Lite keeps base `K=3`. If the committed token appears outside base K but inside the adaptive rank cap, the record widens through the committed rank up to default rank 10. Entropy is not a CI-Lite widening trigger. If the rank is missing or beyond the adaptive window, the rank-overflow flag is set and fallback `chosen_id` is serialized.

`detect_metadata_repetition` is CI-verifiable and emits AST 523 when stable sequence/chunk metadata or AgentOps event fields are repeated in token records. It reports byte categories for sequence headers, chunk headers, compact token records, adaptive payloads, span events, trajectory events, manifests, repeated metadata, compact-token bytes/token, and total artifact bytes/token.

`dualstream.agentops` implements event-scoped trajectory evidence and an AgentOps control-plane manifest binding source, model, prompt, tool, memory, context, guardrail/AST, evaluation, verifier, evidence, budget, rollout, and feature-flag versions. Tool governance and context/memory/RAG checks are part of `validate_agent_trajectory`.

CI profiles live in `dualstream.ci_profiles`: PR uses metadata-amortized `DSA-CI-Lite` with hard fail >24 bytes/token and warning >22 compact-token bytes/token. DSA-Forensic remains an opt-in forensic path with a 256 bytes/token ceiling.

## Day 5 flat-YAML context serialization rule

Deep JSON is still allowed for machine-only APIs, JSON Schema validation, storage, compact evidence transport, and full artifact manifests. Model-facing, evaluator-facing, or human-review context bundles must not inline JSON deeper than three logical levels. When a prompt-visible architecture/context bundle would exceed that depth, serialize it as flat YAML with stable namespaced/path-like keys and bind deeper machine artifacts by hash or artifact id.

`dualstream.context_serialization` provides `serialize_flat_yaml_context_bundle`, `lint_context_payloads`, and `verify_context_serialization`. The linter reports maximum JSON/YAML depth, prompt/evaluator JSON depth violations, flat YAML bundle count, deep schema reference count, and nested context serialization failures. Violations emit AST 706 (`nested context serialization risk`) or AST 707 (`model-facing JSON depth violation`) without changing AST 523 metadata-amortization behavior.

Prompt-visible flat YAML example:

```yaml
agent_context.agentops.source_version: abc123
agent_context.tool_registry.search.input_schema_hash: sha256:input
agent_context.context.current_user_request_hash: sha256:req
agent_context.context.retrieval.primary_artifact_id: doc-42
```

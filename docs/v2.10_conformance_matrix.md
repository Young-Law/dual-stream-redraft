# DSA v2.10 Phase 1 conformance matrix

The authoritative source is `The_Internal_Monologue_DSA_v2.10_portable_hybrid_retention.pdf`, read in full before this corrective change. This matrix is intentionally scoped to Phase 1: compact binary V3.3 evidence, generator integration, canonical hashing, shared API compatibility, and authorized keyed-selection replay. It does not claim complete v2.10 conformance.

| Requirement area | Status | Implementation | Tests | Notes |
|---|---|---|---|---|
| V3.1 decode compatibility | implemented | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Legacy bytes dispatch to the legacy decoder only. |
| V3.2 decode compatibility | implemented | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Existing compact binary layout remains readable. |
| V3.3 binary magic/version dispatch | implemented | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | V3.3 begins with the existing compact-family magic and `0x0303`; `{` is not a discriminator. |
| MonologueSequenceHeader V3.3 | partial | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Fixed-width binary fields for the Phase 1 generation foundation. |
| EvidenceChunk V3.3 | partial | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Chunk order, CRC32, SHA-256 payload hash, and trigger counts are checked. |
| CompactTokenEvidence V3.3 | implemented for Phase 1 | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Uses compact fixed fields and candidate entries, not per-token Python field names. |
| SignalSpanEvent V3.3 | partial | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Sparse binary span encoding is present. |
| EvidenceManifest V3.3 | partial | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Contains canonical artifact hash, header hash, Merkle root, counts, histogram buckets, trigger counts, and selection digest. |
| Canonical artifact hashing | implemented for Phase 1 | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Hash preimage uses the final artifact with the manifest artifact hash field zeroed. |
| Real generator V3.3 emission | implemented for Phase 1 | `dualstream/generator.py`, `dualstream/cli.py` | `tests/test_v210_conformance.py` | `compact_wire_version` defaults to `0x0303`; `0x0302` remains selectable. |
| Shared compact-evidence API compatibility | implemented | `dualstream/compact_evidence.py`, `dualstream/retention.py`, `dualstream/verifier.py` | `tests/test_v210_conformance.py` | Reconstruction, budget summary, verifier API, and CLI budget checks accept V3.3. |
| Authorized keyed replay | implemented for Phase 1 | `dualstream/compact_evidence.py`, `dualstream/verifier.py` | `tests/test_v210_conformance.py` | Unknown key id, wrong key, context mismatch, and trigger tampering are rejected. |
| CI-Lite 10,000-token raw byte ceiling | implemented | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Runtime-generated V3.3 fixture is measured using serialized bytes. |
| CI-Standard 10,000-token raw byte ceiling | implemented | `dualstream/compact_evidence.py` | `tests/test_v210_conformance.py` | Runtime-generated V3.3 fixture is measured using serialized bytes. |

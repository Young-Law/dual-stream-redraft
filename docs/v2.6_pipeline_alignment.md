# DSA-R v2.6 Pipeline Alignment

This reference implementation is aligned to the v2.6 paper revision as a **proxy evaluation harness** (not production security).

## What changed
- Tiered audit scheduler (tier0..tier3) with lightweight risk scoring.
- Level-1 internally motivated sycophancy **proxy** mode for controlled false-premise tests.
- Deterministic fallback routing with retry-budget enforcement.
- Randomized nonce-conditioned audit path metadata.

## Commands
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_level1_sycophancy_proxy.txt --audit-mode tiered --poc-mode level1_sycophancy_proxy`
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_dynamic_ci.txt --audit-mode tiered`
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_fallback_red_state.txt --audit-mode full --max-red-retries 1 --fallback-strategy canned_refusal`
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_randomized_audit.txt --randomized-audit --audit-nonce 12345`

## Artifacts
Inspect `monologue.jsonl`, `audit.json`, and `meta.json` for tier/outcome/nonce/fallback fields.

## Limitations
This raises attack cost under stated assumptions and detects configured answer/evidence inconsistencies; it does not prove deceptive alignment detection or monitor-evasion impossibility.

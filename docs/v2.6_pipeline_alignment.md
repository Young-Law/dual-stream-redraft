# v2.6 Pipeline Alignment

This repository now implements the v2.6 reference pipeline across `dualstream/audit_scheduler.py`, `dualstream/audit.py`, `dualstream/fallback.py`, `dualstream/randomized_audit.py`, and `dualstream/generator.py`.

## Threat model levels
- Level 0 plumbing: host-induced divergence tests.
- Level 1 sycophancy proxy: false-premise prompts that may trigger factuality concern + affirmation checks.
- Level 2 monitor-evasion proxy: randomized nonce-conditioned audit path metadata.

Level 0 is useful for instrumentation but is insufficient for internally motivated deception claims. Level 1 remains a proxy evaluation only.

## Dynamic CI tiers
- Tier0: integrity/schema baseline checks.
- Tier1: deterministic entropy/refusal-mass/AST tripwire checks with structured reasons and risk scoring.
- Tier2: suspicious-window and AST-304/static-evasion escalation with targeted heavy probes.
- Tier3: full ensemble/release-grade audits for nightly/release-blocking/deep CI modes, with forced full telemetry retention by default.

## Deterministic fallback
`dualstream/fallback.py` enforces retry budgets and deterministic routing (`canned_refusal`, `safe_override`, `abort`) with no blind unchanged retry loops.

## Randomized audit metadata
`dualstream/randomized_audit.py` emits `audit_nonce_hash`, `audit_path_id`, and `randomized_probe_selection`.

## Commands
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_dynamic_ci.txt --audit-mode tiered --outdir out_v26`
- `python -m dualstream.cli generate --prompt-file examples/prompts/v26_randomized_audit.txt --randomized-audit --audit-nonce 42 --outdir out_v26_rand`
- `python -m pytest`

## v2.6 scheduler status
The scheduler implementation is functional DSA-R reference logic (not scaffolding): deterministic tier selection, CI-mode policy, selective retention controls, and auditable metrics/reasons. It is not a DSA-P completeness claim.

## Randomized manifest binding
Randomized audit selection is manifest-bound via canonical manifest hashing that preserves top-level type/value; falsy manifests like `None`, `{}`, `[]`, `""`, `0`, and `False` are distinguished.
